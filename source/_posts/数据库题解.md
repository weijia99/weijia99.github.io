## 打印出1班数学前2名的学生信息（百度）
```sql
select b.sname, c.sid ,  c.cname,c.score 
FROM result AS c , student AS b
where c.sid = b.sid and b.classid=1
AND c.cname="数学"
ORDER BY c.score desc
LIMIT 2
```

## <font style="background-color:#FBDE28;">求各个科目前3名的学生（腾讯）</font>
```sql
SELECT b.sname, c.sid, c.cname, c.score
FROM result AS c
JOIN student AS b ON c.sid = b.sid
WHERE  (
  -- 自查训
  select count(distinct score)
  from result as r1
  where r1.courseid = c.courseid
  and score>c.score
) <3
ORDER BY c.cname, c.score DESC;

```

## 查询平均分低于80的
```sql
SELECT b.sname , b.sid  , avg(c.score) as av
FROM result AS c ,
student as b
where c.sid = b.sid
group by b.sid , b.sname
HAVING  avg(c.score) < 80



```

## 求低于69 家伙的平均分
```sql

select name , avg(course_score) as sc 
FROM t_student 
where student_id in (
SELECT DISTINCT student_id 
from t_student
WHERE course_score < 60) 
group by name
order by sc desc
```

## <font style="background-color:#FBDE28;">年龄段分层</font>
使用分段函数，构造新的id18-29，然后再使用这个id来进行聚合

```sql
-- 年龄段分层
select 
CASE 
	WHEN age>=0 and age<18 then
		'0-17'
		WHEN age>=18 and age<29 then
		'18-29'
		WHEN age>=30 and age<59 then
		'30-29'
	ELSE
		'60+'
END as judge,
count(*)
from user 
group by judge

```

## 订单表（单表）
有个订单表t order,有id、money、country:字段

查找country是中国的，money倒序的第100条到第200条

记录（顺丰）

```sql
select * 
from t_order 
where country="中国"
order by money DESC
limit 100 offset 99
```

使<font style="background-color:#FBDE28;">用offset自动移除前面的99个，然后限制查找100个</font>
